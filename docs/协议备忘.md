# 协议备忘(实测记录)

以下结论均为实机抓包/接口验证所得,改动 `app/sources/` 与 `app/printers/` 前请先读这里。

## MakerWorld

无公开 API,以下路径为逆向所得。**国内站与国际站是两套独立的 ID 空间** ——
同一个数字 ID 在 `api.bambulab.cn` 与 `api.bambulab.com` 上对应完全不同的模型,
因此解析分享链接时必须按域名选择 API 区域。

- 搜索 `GET /v1/search-service/select/design2?keyword&limit&offset&orderBy`
- 详情 `GET /v1/design-service/design/{id}`(返回 `instances[].profileId`)
- 下载 `GET /v1/iot-service/api/user/profile/{profileId}?model_id=`(Bearer token)→ 签名 S3 直链
- `makerworld.com` 网页端有 Cloudflare,直接走 API 已完全绕开

国际站设计被镜像到国内站时会分配**新的 ID**,但封面文件名、实例顺序一一对应,
创作者名在镜像侧带 `GLB_` 前缀而 `name` 一致 —— 这三点是判定「同一模型」的依据,
`MakerWorldAdapter.resolve_cn_twin()` 据此把国际站条目映射到中文镜像条目
(国际站的 `titleTranslated` / `summaryTranslated` 字段恒为空,上游没有机器翻译)。

## 创想 K 系列

- 本地控制:`ws://ip:9999` 遥测 + FTP 上传 + WS 指令(社区逆向,指令模板可配置)
- 摄像头是私有 WebRTC 协议(9999 信令),**没有本地 HTTP 快照接口**;
  只能由 go2rtc 以 `webrtc:http://<host>:8000/call/webrtc_local#format=creality`
  接入后截帧,且容器必须是 host 网络 —— ICE 候选须为宿主机 LAN IP,
  bridge 容器的地址打印机不可达(实测结论,不要为了"更干净"改回 bridge 网络)
- 创想云(`crealitycloud.com`)接口未适配,分享链接导入会明确返回"即将支持"

## Klipper / Moonraker

REST 接口文档完善,适配器即写即用。
摄像头走 `/server/webcams/list` 注册的快照地址,退回常见 mjpeg-streamer 路径。
Moonraker 的 CORS 对任意 Origin 开放、WS 不校验 Origin —— 这是本项目选择
「服务端直连 + 局域网访问」而不是浏览器直连的原因之一。

## 切片器

Creality Print 7.2 本机安装后,`resources/profiles/Creality/` 内含官方 K2 Plus
参数包(机器/耗材/工艺 JSON,Orca 系格式),`server/profiles/` 由此整理而来。

OrcaSlicer CLI 对高版本工程文件返回 `CLI_FILE_VERSION_NOT_SUPPORTED`(-24),
原因见 `app/slicing/orca_cli.py` 注释:MakerWorld 现下发 2.5.x 产出的工程 3MF,
高于 Orca 2.4.2 的版本号即拒载,靠 `--allow-newer-file` 裸 flag 跳过。
